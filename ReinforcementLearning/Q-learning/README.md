### 1. 核心概念：直觉理解

想象你在玩一个从未见过的游戏，没有说明书。你的目标是**获得最高分**。

-   **状态：** 你当前站在地图的哪个格子。
-   **动作：** 你可以选择“上、下、左、右”。
-   **奖励：** 走到宝箱 +100 分，掉进陷阱 -100 分，每走一步 -1 分（鼓励快速到达）。
-   **Q值：** 这是一个“经验值”。$Q(s, a)$ 表示：**“在状态 $s$ 下，采取动作 $a$，未来总共能拿多少分”**。

> 💡 **核心思想**
> Q-learning 的本质就是**背答案**。Agent 维护一张巨大的表格（Q-table），记录每个状态下每个动作的价值。通过不断试错，把这张表填得越来越准，最后只要查表选最大值对应的动作，就能完美通关。

---

### 2. 数学原理：Q-table 是如何更新的？

Q-learning 的核心是 **贝尔曼方程 (Bellman Equation)** 的变体。

#### 更新公式
$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \underbrace{\left[ r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t) \right]}_{\text{TD Error (时序差分误差)}}$$

别被公式吓到，我们拆解来看：

| 符号 | 含义 | 通俗解释 |
| :--- | :--- | :--- |
| $s_t, a_t$ | 当前状态和动作 | 我现在在哪，做了什么 |
| $r_{t+1}$ | 即时奖励 | 做完这一步立刻得到的反馈 |
| $\gamma$ | 折扣因子 (0~1) | **远见程度**。$\gamma=0$ 只看眼前；$\gamma=0.99$ 非常看重未来 |
| $\max_{a'} Q(s_{t+1}, a')$ | 下一状态的最大Q值 | 假设我下一步会做出**最优选择**能得到的价值 |
| $\alpha$ | 学习率 (0~1) | **步长大小**。太大容易震荡不收敛，太小学得慢 |
| TD Error | 方括号内整体 | “现实”与“预期”的差距。如果为0，说明预测完美 |

#### ⚠️ 重要特性：Off-Policy（异策略）
注意公式中用的是 $\max_{a'}$，这意味着**更新目标时假设下一步是最优的**，但实际执行动作时可以是随机的。这就是 Q-learning 被称为 Off-Policy 的原因：学习和行动可以分离。

---

### 3. 关键机制：探索 vs 利用

如果 Agent 总是选当前 Q 值最大的动作，它可能永远发现不了更好的路径（陷入局部最优）。我们需要 **$\epsilon$-greedy 策略**：

-   以 $\epsilon$ 的概率：**随机选一个动作**（探索未知）
-   以 $1-\epsilon$ 的概率：**选 Q 值最大的动作**（利用已知）

> 📉 **衰减策略**
> 训练初期 $\epsilon$ 设大一点（如 1.0），让 Agent 疯狂探索；随着训练进行逐渐减小（如降到 0.01），让 Agent 趋于稳定利用。

### 5. 局限与进阶方向

学完上面的内容，你已经掌握了 Q-learning 的全部精髓。但你需要知道它的边界：

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| **状态空间爆炸** | Q-table 大小 = 状态数 × 动作数。围棋有 $10^{170}$ 种状态，根本存不下 | **DQN**：用神经网络拟合 Q 函数代替表格 |
| **过估计** | $\max$ 操作倾向于高估 Q 值 | Double Q-learning / Dueling DQN |
| **样本效率低** | 需要大量交互才能收敛 | Experience Replay + Target Network |
| **只支持离散动作** | 无法处理连续控制（如机器人关节角度） | DDPG / SAC / PPO |

# 关键问题

1. 为什么`terminated=True` 时 `best_next_q`要设为0？
> 因为终止状态没有未来，未来的预期收益必须为0.

2. 如果把gamma设为0，会发生什么？
> Q值不再包含任何对未来的预期，它仅仅是对“当前这一步即时奖励 r的移动平均估计。
> 本质上，从MDP退化为多臂老虎机，不考虑状态转移，不考虑长期累积回报，不考虑单步即时收益。
> Q-Learning丧失了规划能力，退化为只看眼前利益的短视算法。
